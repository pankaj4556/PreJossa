# Visual Assets & Design Credits

All visuals, vector illustrations, and backgrounds in the PreJOSAA scroll-driven landing page are custom-crafted, royalty-free, and procedurally generated:

1. **Procedural Grain Overlay**:
   - Built with native SVG `feTurbulence` filter with zero network dependencies.

2. **Panel 1 — Counselling Mesh & Particles**:
   - Custom SVG coordinate radial gradient mesh and canvas-driven orbital constellation particles.

3. **Panel 2 — College Parallax Campus**:

4. **Panel 3 — Branch Decision Tree**:
   - Custom procedural SVG node-and-connector network with dynamic stroke dash array animation.

5. **Panel 4 — Placement Comparative Chart**:
